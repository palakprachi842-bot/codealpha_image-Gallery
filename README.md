# 📸 PixelVault – Responsive Image Gallery

### CodeAlpha Frontend Development Internship | Task 1

PixelVault is a modern, responsive image gallery website developed using **HTML, CSS, and JavaScript** as part of the CodeAlpha Frontend Development Internship.

The project provides an interactive experience where users can explore beautiful images, filter them by category, and view them in a lightbox with smooth navigation.

## ✨ Features

- **Responsive Design** – Works on desktops, tablets, and mobile devices.
- **Image Gallery** – Displays images in a modern grid layout.
- **Category Filters** – Filter images by Nature, City, and Animals.
- **Lightbox Viewer** – Click any image to view it in a larger format.
- **Next/Previous Navigation** – Navigate between images easily.
- **Hover Effects** – Smooth zoom effects and image overlays.
- **Keyboard Support** – Use arrow keys for navigation and Escape to close the lightbox.
- **Modern UI** – Elegant dark theme with gold accents.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, animations, and responsive layouts
- **JavaScript** – DOM manipulation, event handling, filtering, and image navigation
- **Unsplash** – Online image sources

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.
4. Explore the gallery and its interactive features.

**Note:** An internet connection is required to load the images from Unsplash.
